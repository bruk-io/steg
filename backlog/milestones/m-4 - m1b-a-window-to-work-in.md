## Description

One window with tabs and split panes, a shell that draws correctly and keeps up with typing, copy and paste, key bindings, status for typed commands, and a session that is still there after quitting and reopening. No palette, status ring or polish. The second usable stopping point inside M1, decided by Bruk on 2026-11-15. Spec doc-1, section 6.
